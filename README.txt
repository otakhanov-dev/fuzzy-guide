GitHub Pages 업로드 안내

이 폴더에는 세 가지 파일이 있습니다.
- index.html : 페이지 내용과 한국어 문구
- style.css : 디자인과 애니메이션
- script.js : 별 생성과 버튼 동작

세 파일을 모두 GitHub 저장소의 최상위 폴더(root)에 업로드하세요.
HTML 파일 이름은 반드시 index.html이어야 합니다.
Settings > Pages > Deploy from a branch > main > /(root) 를 선택하고 저장하세요.
배포 후 GitHub Pages 주소를 누나에게 보내면 됩니다.
